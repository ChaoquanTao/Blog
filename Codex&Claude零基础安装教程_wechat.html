桌面端零基础安装教程

客户端是四肢，模型是大脑
十几分钟，让 AI 帮你操作电脑

写在前面

很多人第一次接触 Claude、Codex 时，最先卡住的不是"怎么用"，而是"我到底要装什么"。本文先讲清概念，再按需求给出三种方案，最后附上一个最省事的选择。
本文整理自小红书博主「去薯条整点码头」的笔记《Codex & Claude 零基础安装教程》，截图来自原笔记。

01

先搞清楚几个概念

模型和 harness（客户端）

当我们说"用 Claude"时，其实指的是一个比较宽泛的东西。以 Claude 为例，它大致分为三部分：

🧠 模型

真正负责思考的部分，比如 Claude Opus、Sonnet。

💻 桌面端（Claude Desktop）

装在电脑上的应用，能读写文件、操作软件。本文的重点。

⌨️ 命令行（Claude Code）

主要给程序员用，本文不展开。

"

模型是大脑，客户端是四肢。大脑能思考，但没法帮你搬起一个箱子。

如果你希望 AI 直接操作你的电脑——写一篇论文存到本地、调用剪辑软件剪视频、整理一个文件夹——就需要一个桌面端来充当"四肢"。

理解了这一点就会发现：客户端和模型是可以分开选的。桌面端用 Claude 或 Codex，背后的模型却可以换成 DeepSeek、GitHub Copilot 提供的模型。这正是后面几种方案的核心思路。

你想用 AI 做什么？

💬 只是聊天、问问题

不需要桌面端，网页版就够了：claude.ai、chatgpt.com、gemini.google.com；没有海外网络环境的话，chat.deepseek.com 也是不错的选择。

🛠 希望 AI 操作你的电脑

整理报表、清理磁盘、批量处理文件……这些耗费人力的事，请继续往下看。

02

下载和安装
情况安装方式
Mac + 能访问海外网站在 chatgpt.com/download 和 claude.com/download 下载 dmg 安装包
Mac + 无海外网络使用原作者提供的网盘安装包（见文末）
Windows使用网盘安装包一键安装（见文末）

注意事项

访问海外网站时节点不要选香港，选日本、新加坡等地区——OpenAI、Anthropic 的服务都不支持香港地区。非官方渠道的安装包请自行甄别来源，有条件尽量从官网下载。

03

三种使用方案

装好桌面端之后，关键是给它接上一个"大脑"。原作者给出了三种组合：

方案一 · 便宜高效版 ✅ 推荐

Codex / Claude 桌面端 + DeepSeek API，按量付费，十块钱起。

方案二 · 浅尝 Opus 版 ✅ 推荐

Codex / Claude 桌面端 + GitHub Copilot 订阅，需要信用卡。

方案三 · 高风险版 ❌ 不推荐

Claude 桌面端 + Claude 官方订阅。

前两个方案都用到同一个工具：cc-switch。它能让 Claude / ChatGPT 的桌面端连接其他模型提供商，相当于在桌面端和模型之间加了一个"转接头"。

方案一：桌面端 + DeepSeek API

1

安装 cc-switch

到 ccswitch.io 下载安装 cc-switch。打开后左侧是它支持的各类客户端（Claude Code、Claude Desktop、Codex 等），右侧是当前客户端配置的模型供应商。

2

在 DeepSeek 开放平台充值

打开 platform.deepseek.com，在左侧「充值」页面充值，十块钱就够先体验一阵。首次使用可能需要先完成实名认证。

图 1　DeepSeek 开放平台充值页面

3

创建 API Key

在平台左侧进入「API keys」，点击右上角「创建 API key」。

图 2　创建 DeepSeek API Key

⚠️ 这个 Key 非常重要，千万不要泄露给别人，否则别人也能消耗你充值的额度！Key 一般只在创建时完整显示一次，记得妥善保存。

4

在 cc-switch 里选择客户端

打开 cc-switch，在左侧选择你要用的桌面端：用 Claude 就选 Claude Desktop，用 ChatGPT 就选 Codex。

图 3　在 cc-switch 左侧选择 Claude Desktop

5

添加 DeepSeek 供应商

点击右上角「添加供应商」，在「模型厂商」分类里找到 DeepSeek。

图 4　在供应商列表中选择 DeepSeek

然后在 API Key 一栏填入刚刚创建的 Key。下面的请求地址、模型映射等配置会自动填好，不用改。

图 5　填入 DeepSeek API Key

6

保存并启用

点击「添加」保存。回到列表，确认上方切到「路由」模式，DeepSeek 一栏显示「路由中」。

图 6　DeepSeek 已处于路由中

7

重启桌面端验证

重启 Claude / ChatGPT 桌面端。左下角变成 Gateway、右下角模型变成 deepseek，就说明配置成功了。

图 7　左下角显示 Gateway，模型为 deepseek-flash

方案二：桌面端 + GitHub Copilot

配置方式和方案一几乎一样，只是把后端模型从 DeepSeek 换成了 GitHub Copilot。Copilot 的订阅集成了众多模型，其中就包括 Claude Opus。想体验 Opus 的话这是个不错的选择，缺点是需要一张能付美元的信用卡。

1

选择套餐

进入 github.com/features/copilot/plans 查看订阅套餐（原作者截图时为 Free / Pro $10 / Pro+ $39 / Max $100 每月，以官网为准）。

图 8　GitHub Copilot 订阅套餐

不同套餐能用的模型不一样。按原作者截图时的情况，要用 Opus 5.5 需要 Pro+ 及以上套餐。

图 9　各套餐支持的模型对比

2

订阅

点击 Get started，没有 GitHub 账号的先注册登录，然后绑定信用卡付款。

3

在 cc-switch 中添加 GitHub Copilot

打开 cc-switch →「添加供应商」→「账号登录」分类里选择 GitHub Copilot，按提示用 GitHub 账号登录授权。之后同样保存、启用、重启桌面端。

图 10　在 cc-switch 中选择 GitHub Copilot

方案三：Claude 官方订阅（不推荐）

原作者明确不推荐：操作最复杂，风险也最高。Claude 官方服务不支持中国大陆地区，在不支持的地区注册或使用违反其服务条款，账号很容易被封禁，订阅费用也可能打水漂。

如果你本身就身处 Claude 支持的地区，直接在 claude.ai 注册订阅、下载桌面端登录即可，这是最省心的官方用法。

04

最省事的选择

看到这里你可能会发现：你真正需要的，可能只是一个好用的桌面端 + 一个好用的模型。有没有最省事的方式？有的。

DeepSeek 自己的桌面端

充值 DeepSeek API 后直接使用，不需要 cc-switch 转接。地址：deepseek.com/harness

Codex + ChatGPT 订阅

需要海外网络环境，每月 20 美元。据原作者说最近 ChatGPT 频繁重置额度，性价比也不错。

05

一张表帮你选
你的需求建议
只是聊天问问题网页版就够了
让 AI 操作电脑，预算有限桌面端 + cc-switch + DeepSeek API
想体验 Claude Opus桌面端 + cc-switch + Copilot Pro+
想要最省事DeepSeek 桌面端，或 Codex + ChatGPT 订阅

核心思路就一句话：
客户端是四肢，模型是大脑，两者可以自由组合。
按需求和预算挑一个组合，十几分钟就能用起来。
